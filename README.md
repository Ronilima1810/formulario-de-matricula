Formulário de Matrícula - Estrela do Amanhã 🌟

📖 Sobre o Projeto

Este é um projeto de front-end de um formulário de matrícula para a escola fictícia "Estrela do Amanhã". O desafio foi criar uma interface limpa, moderna e responsiva, com foco na usabilidade e na estilização avançada de componentes de formulário.

O design apresenta um layout de duas colunas: o formulário principal à esquerda (com scroll independente) e um painel de informações fixo à direita.

Este projeto foi desenvolvido como parte de um estudo/curso (possivelmente da Rocketseat), aplicando conceitos modernos de HTML5, CSS3 e SASS.

✨ Funcionalidades Principais

Layout de Duas Colunas: Painel de formulário com rolagem independente (overflow: auto) e painel lateral fixo.

Design Responsivo: Utiliza Flexbox e Grid Layout (com repeat(auto-fit, ...)) para se adaptar a diferentes tamanhos de tela.

Componentes de Formulário Customizados:

Inputs de data com ícone customizado.

Botões de rádio (Radio buttons) estilizados como caixas de seleção interativas (Turno, Esportes).

Área de "Dropzone" para upload de arquivos com feedback visual.

Estilização Avançada com SASS: O código utiliza SASS (SCSS) para uma estilização organizada, aninhada e de fácil manutenção (variáveis, nesting).

Seletores CSS Modernos: Uso de :has(), :focus-within e input:focus para criar interações ricas e feedback visual para o usuário.

🛠️ Tecnologias Utilizadas

HTML5 (Estrutura semântica)

SASS (SCSS) (Pré-processador CSS para aninhamento e variáveis)

CSS3 (Grid, Flexbox, Variáveis CSS, Seletores Avançados)

JavaScript (Manipulação de CEP - se você adicionou)

🚀 Como Rodar o Projeto

Este projeto utiliza SASS. Para que os estilos funcionem, os arquivos .scss precisam ser "compilados" para .css.

A forma mais fácil de fazer isso no VS Code é usando a extensão Live Sass Compiler.

Clone este repositório:

git clone https://github.com/Ronilima1810/formulario-de-matricula


Abra o projeto no VS Code.

Instale a extensão Live Sass Compiler.

Clique em "Watch Sass" na barra de status do VS Code. Isso irá gerar os arquivos .css automaticamente.

Abra o index.html (de preferência com a extensão Live Server).
